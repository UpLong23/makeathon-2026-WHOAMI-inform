# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/f85b8a5c-1693-4fb5-b4dd-e1962bc4637a

## Run Locally

**Prerequisites:**  Node.js

1. Clone Project
```sh
git clone https://github.com/Marootinos/Receipt-Agent.git
```
2. Navigate to Project
```sh
cd Receipt-Agent
```
3. Install dependencies:
```sh
npm install
```
4. Run the app:
```sh
npm run dev
```
